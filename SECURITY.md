# Security Policy

## Supported Versions

The current public beta line is `0.1.x`.

## Reporting A Vulnerability

Please report security issues privately to the maintainers before opening a
public issue. Include:

- Obsidian version
- Stellar Graph version
- operating system
- steps to reproduce
- whether the issue requires a specific vault structure

Stellar Graph should not execute note content or make network requests. Any
behavior that violates that expectation should be treated as high severity.
